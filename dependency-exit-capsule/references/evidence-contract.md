# Evidence Contract (shared between scripts)

Every script reads/writes JSON. Every top-level block carries an `evidence_tag`:

| Tag            | Meaning                                              | Produced by                          |
|----------------|------------------------------------------------------|--------------------------------------|
| `OBSERVED`     | Read directly from repo files / registry metadata     | `scan_usage.py`, `collect_metadata.py` |
| `EXECUTED`     | Result of a command we actually ran (tests, builds)   | `run_tests.py`                       |
| `AI-SUGGESTED` | Generated by the open-weight model, not verified      | `ai_analyze.py`                      |

## 1. `evidence.json` (Member A → Member B)

```json
{
  "dependency": "request",
  "version": "2.88.2",
  "ecosystem": "npm",
  "usages": [
    {"file": "src/http/client.js", "line": 3, "snippet": "const request = require('request');", "kind": "import"}
  ],
  "metadata": {"license": "Apache-2.0", "latest_version": "2.88.2", "last_release": "2020-02-11",
               "deprecated": true, "deprecation_message": "request has been deprecated", "evidence_tag": "OBSERVED"},
  "risk_indicators": [{"name": "deprecated", "value": true, "evidence_tag": "OBSERVED"}],
  "evidence_tag": "OBSERVED"
}
```

## 2. `tests_<label>.json` (from `run_tests.py`, tag `EXECUTED`)

Key fields: `status` (`passed|failed|error|timeout|not_run`), `command`, `exit_code`,
`counts {passed, failed, errors, skipped, total}`, `failed_tests[]`, `log_path`, `parse_confidence`.

## 3. `ai_analysis.json` (from `ai_analyze.py`, tag `AI-SUGGESTED`)

Key fields: `model {provider, name, temperature}`, `analysis {...}`, `grounding {...}`.
`grounding` is the result of checking the AI's file references against observed usages. That check is
deterministic, so it counts as verified, not as AI output.

## 4. `tests_compare.json` (from `run_tests.py compare`, tag `EXECUTED`)

`newly_failing[]`, `fixed[]`, `delta {passed, failed, ...}`, `verdict`.
